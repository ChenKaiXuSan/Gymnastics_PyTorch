# Pegasus job scripts (cycle-aware fusion)

NQSV job scripts. Default budget `HP260146` on queue `gen_S` (the HP260146
project cannot use the `gpu` queue); `ACCOUNT=SKIING QUEUE=gpu` switches to
the SKIING budget on the gpu queue. `cycle_aware_fold_qsub_hp.sh` is an
equivalent copy of the fold script pinned to `gen_S`. The
repository is mounted at `/work/HP260146/chenkaixu/Gymnastics_PyTorch` on
the nodes and the private data root at `/work/HP260146/chenkaixu/gymnastics`;
the jobs use the `sam_3d_body` conda environment (torch 2.10 + CUDA,
PyTorch Lightning 2.6, Hydra 1.3).

Protocol: 5-fold subject-disjoint cross-validation, single seed (0), 50 epochs.

| script | purpose |
|---|---|
| `submit_cycle_aware_5fold.sh <dataset> [experiment]` | submit the 5 folds of one dataset as 5 jobs (recommended entry point) |
| `cycle_aware_fold_qsub.sh` | one fold (`DATA`, `FOLD`, `SWEEP`, ...) on the SKIING account / `gpu` queue |
| `cycle_aware_fold_qsub_hp.sh` | same job on the HP260146 account / `gen_S` queue (`ACCOUNT=HP260146` in the submitter); each account has its own cap of about 25 queued requests |
| `cycle_aware_train_qsub.sh` | one run with the dataset's default split (`DATA`, `RUN_NAME`, ...) |
| `submit_cycle_aware_transfer.sh <ckpt> <protocol> [sweep]` | evaluate one checkpoint on every fold of a target protocol (zero-shot transfer, `test_only=true`) |

Fold files: `configs/cycle_aware/folds/gymnastics/fold_01..05.json` (137
people, stratified elderly / student, generated by
`python -m gymnastics.fusion.data.folds`),
`configs/fusion/folds/freeman/fold_01..05.json` (the existing 17-subject
FreeMan protocol, comparable with the rotation-aware results) and
`configs/cycle_aware/folds/freeman_all40/fold_01..05.json` (all 40 FreeMan
subjects, 905 sessions; groups balanced by session count, generated with
`--freeman-manifests local/runs/freeman_benchmark_cluster/manifests`).

## Prerequisites (once, login node)

```bash
gymnastics align cycles private     # cycle middles in the 137 alignment records
gymnastics align cycles freeman     # local/runs/cycle_records/freeman
gymnastics align cycles index       # unified tree + index
```

## Typical use

```bash
# Baseline, both datasets, 5 folds each.
bash pegasus/submit_cycle_aware_5fold.sh gymnastics
bash pegasus/submit_cycle_aware_5fold.sh freeman           # 17-subject protocol
bash pegasus/submit_cycle_aware_5fold.sh freeman_all40     # all 40 subjects

# Ablations (one sweep per preset: no_film, no_cross_view, no_short_motion,
# no_long_motion, no_phase, equal_reliability, no_residual, pose_only, full_skeleton, full_context).
bash pegasus/submit_cycle_aware_5fold.sh gymnastics no_film

# Single run on the fixed paper split (96/27/14).
qsub -o local/runs/cycle_aware/joblogs/gym_v1_seed0.log -v DATA=gymnastics,RUN_NAME=gym_v1_seed0 \
     pegasus/cycle_aware_train_qsub.sh

# Reference-supervised training on all 40 FreeMan subjects, then zero-shot
# transfer of a fold checkpoint to the private 5 folds.
bash pegasus/submit_cycle_aware_5fold.sh freeman_all40 reference_supervised
bash pegasus/submit_cycle_aware_transfer.sh \
     local/runs/cycle_aware/freeman_all40_v1_reference_supervised_5fold_seed0/fold_01/checkpoints/last.ckpt gymnastics

# Robustness evaluation of existing checkpoints (fixed corruption replayed on test windows).
bash pegasus/submit_cycle_aware_transfer.sh <ckpt> gymnastics <sweep> "data.test_with_corruption=true"

# Measurement-quality regularisation (periodicity 0.5 + half-cycle symmetry 0.2).
bash pegasus/submit_cycle_aware_5fold.sh gymnastics measurement

# Collect a finished sweep: per-fold test metrics, mean +- sd.
PYTHONPATH=src python -m gymnastics.fusion.summarize local/runs/cycle_aware/gymnastics_v1_5fold_seed0
```

Outputs: `local/runs/cycle_aware/<sweep>/<fold>/{config.yaml,logs/,checkpoints/,result.json}`,
job logs in `local/runs/cycle_aware/joblogs/`, sweep summary in
`local/runs/cycle_aware/<sweep>/summary.{json,csv}`.

# Pegasus job scripts (cycle-aware fusion)

NQSV job scripts for the cluster gpu queue (`#PBS -A SKIING -q gpu`). The
repository is mounted at `/work/HP260146/chenkaixu/Gymnastics_PyTorch` on
the nodes and the private data root at `/work/HP260146/chenkaixu/gymnastics`;
the jobs use the `sam_3d_body` conda environment (torch 2.10 + CUDA,
PyTorch Lightning 2.6, Hydra 1.3).

Protocol: 5-fold subject-disjoint cross-validation, single seed (0), 50 epochs.

| script | purpose |
|---|---|
| `submit_cycle_aware_5fold.sh <dataset> [experiment]` | submit the 5 folds of one dataset as 5 jobs (recommended entry point) |
| `cycle_aware_fold_qsub.sh` | one fold (`DATA`, `FOLD`, `SWEEP`, ...) |
| `cycle_aware_train_qsub.sh` | one run with the dataset's default split (`DATA`, `RUN_NAME`, ...) |

Fold files: `configs/cycle_aware/folds/gymnastics/fold_01..05.json` (137
people, stratified elderly / student, generated by
`python -m gymnastics.fusion.cycle_aware.data.folds`) and
`configs/fusion/folds/freeman/fold_01..05.json` (the existing FreeMan
protocol).

## Prerequisites (once, login node)

```bash
gymnastics align cycles private     # cycle middles in the 137 alignment records
gymnastics align cycles freeman     # local/runs/cycle_records/freeman
gymnastics align cycles index       # unified tree + index
```

## Typical use

```bash
# Baseline, both datasets, 5 folds each.
bash pegasus/submit_cycle_aware_5fold.sh gymnastics
bash pegasus/submit_cycle_aware_5fold.sh freeman

# Ablations (one sweep per preset: no_film, no_cross_view, no_short_motion,
# no_long_motion, no_phase, equal_reliability, no_residual, pose_only, full_skeleton, full_context).
bash pegasus/submit_cycle_aware_5fold.sh gymnastics no_film

# Single run on the fixed paper split (96/27/14).
qsub -o local/runs/cycle_aware/joblogs/gym_v1_seed0.log -v DATA=gymnastics,RUN_NAME=gym_v1_seed0 \
     pegasus/cycle_aware_train_qsub.sh

# Collect a finished sweep: per-fold test metrics, mean +- sd.
PYTHONPATH=src python -m gymnastics.fusion.cycle_aware.summarize local/runs/cycle_aware/gymnastics_v1_5fold_seed0
```

Outputs: `local/runs/cycle_aware/<sweep>/<fold>/{config.yaml,logs/,checkpoints/,result.json}`,
job logs in `local/runs/cycle_aware/joblogs/`, sweep summary in
`local/runs/cycle_aware/<sweep>/summary.{json,csv}`.

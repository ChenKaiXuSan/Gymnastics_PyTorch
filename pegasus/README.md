# Pegasus job scripts

Every NQSV job script of the repository lives here, named by the stage it
serves: `fusion_*` / `submit_fusion_*` (stage 4, the proposed model),
`archive_*` (the frozen rotation-aware paper model) and
`benchmark_*` (SAM3D inference on the public benchmarks:
`benchmark_freeman_subject_qsub.sh` per FreeMan subject,
`benchmark_sportspose_infer_qsub.sh` + `submit_sportspose_infer.sh` for the
two selected views of every SportsPose clip, ~4 subjects per job).

`submit_fusion_5fold.sh` passes the checkout that holds it to the jobs
(`REPO`), so a sweep can be pinned to a git worktree while the main tree
keeps changing (symlink the worktree's `local/` to the main one).

## Fusion model (stage 4)

NQSV job scripts. Default budget `HP260146` on queue `gen_S` (the HP260146
project cannot use the `gpu` queue); `ACCOUNT=SKIING QUEUE=gpu` switches to
the SKIING budget on the gpu queue. `fusion_fold_qsub_hp.sh` is an
equivalent copy of the fold script pinned to `gen_S`. The
repository is mounted at `/work/HP260146/chenkaixu/Gymnastics_PyTorch` on
the nodes and the private data root at `/work/HP260146/chenkaixu/gymnastics`;
the jobs use the `sam_3d_body` conda environment (torch 2.10 + CUDA,
PyTorch Lightning 2.6, Hydra 1.3).

Protocol: 5-fold subject-disjoint cross-validation, single seed (0), 50 epochs.

| script | purpose |
|---|---|
| `submit_fusion_5fold.sh <dataset> [experiment]` | submit the 5 folds of one dataset as 5 jobs (recommended entry point) |
| `fusion_fold_qsub.sh` | one fold (`DATA`, `FOLD`, `SWEEP`, ...); the submitter passes `-A/-q` (HP260146/`gen_S` by default, `ACCOUNT=SKIING` -> `gpu`) |
| `fusion_fold_qsub_hp.sh` | equivalent copy pinned to HP260146 / `gen_S` |

Every fold job trains with `data.num_workers=8` (`NUM_WORKERS` in the job
scripts defaults to 8 since 2026-09-21; do not submit with 0), bf16-mixed and
TF32 matmuls, i.e. the config defaults.

Requests are 3 h (`elapstim_req`): a fold takes about an hour and a short
request backfills into scheduling gaps. The only hard cap is the project
budget in GPU-hours: `qsub` reserves `elapstim_req x gpunum` at submission
and refuses ("Budget exceeded") when the reservation exceeds the remainder;
check with `rbudgetcheck -a`. Scheduling order is the user's past-usage rank
plus one point per hour waited (`sstat -f <request>` shows the breakdown);
`qattach -c "nvidia-smi" <request>` samples a running job's node.
| `fusion_train_qsub.sh` | one run with the dataset's default split (`DATA`, `RUN_NAME`, ...) |
| `submit_fusion_transfer.sh <ckpt> <protocol> [sweep]` | evaluate one checkpoint on every fold of a target protocol (zero-shot transfer, `test_only=true`) |

## Archived rotation-aware model and FreeMan benchmark

| script | purpose |
|---|---|
| `archive_rotation_aware_train_qsub.sh` | one training run of the archived model (`CONFIG`, `RUN_ID`, `ABLATION`, optional `FOLD`, `SEED`) |
| `archive_freeman_fold_qsub.sh` | one FreeMan subject-disjoint fold of the archived model (`FOLD`, `SEED`) |
| `archive_freeman_eval_qsub.sh` | out-of-fold evaluation / zero-shot scoring of archived-model checkpoints on FreeMan (`STAGE=evaluate|zero-shot`) |
| `benchmark_freeman_subject_qsub.sh` | SAM3D-Body inference + fusion + evaluation of one FreeMan subject (`SUBJECT`, `FRAME_STRIDE`) |

Fold files: `src/configs/fusion/folds/gymnastics/fold_01..05.json` (137
people, stratified elderly / student, generated by
`python -m fusion.data.folds`),
`src/configs/shared/folds/freeman/fold_01..05.json` (the existing 17-subject
FreeMan protocol, comparable with the rotation-aware results) and
`src/configs/fusion/folds/freeman_all40/fold_01..05.json` (all 40 FreeMan
subjects, 905 sessions; groups balanced by session count, generated with
`--freeman-manifests local/runs/freeman_benchmark_cluster/manifests`).

## Typical use

```bash
# Baseline, both datasets, 5 folds each.
bash pegasus/submit_fusion_5fold.sh gymnastics
bash pegasus/submit_fusion_5fold.sh freeman           # 17-subject protocol
bash pegasus/submit_fusion_5fold.sh freeman_all40     # all 40 subjects

# Ablations (one sweep per preset: no_film, no_cross_view, no_short_motion,
# no_long_motion, no_phase, equal_reliability, no_residual, pose_only, full_skeleton, full_context).
bash pegasus/submit_fusion_5fold.sh gymnastics no_film

# Single run on the fixed paper split (96/27/14).
qsub -o local/runs/cycle_aware/joblogs/gym_v1_seed0.log -v DATA=gymnastics,RUN_NAME=gym_v1_seed0 \
     pegasus/fusion_train_qsub.sh

# Reference-supervised training on all 40 FreeMan subjects, then zero-shot
# transfer of a fold checkpoint to the private 5 folds.
bash pegasus/submit_fusion_5fold.sh freeman_all40 reference_supervised
bash pegasus/submit_fusion_transfer.sh \
     local/runs/cycle_aware/freeman_all40_v1_reference_supervised_5fold_seed0/fold_01/checkpoints/last.ckpt gymnastics

# Robustness evaluation of existing checkpoints (fixed corruption replayed on test windows).
bash pegasus/submit_fusion_transfer.sh <ckpt> gymnastics <sweep> "data.test_with_corruption=true"

# Measurement-quality regularisation (periodicity 0.5 + half-cycle symmetry 0.2).
bash pegasus/submit_fusion_5fold.sh gymnastics measurement

# Collect a finished sweep: per-fold test metrics, mean +- sd.
PYTHONPATH=src python -m fusion.summarize local/runs/cycle_aware/gymnastics_v1_5fold_seed0
```

Outputs: `local/runs/cycle_aware/<sweep>/<fold>/{config.yaml,logs/,checkpoints/,result.json}`,
job logs in `local/runs/cycle_aware/joblogs/`, sweep summary in
`local/runs/cycle_aware/<sweep>/summary.{json,csv}`.

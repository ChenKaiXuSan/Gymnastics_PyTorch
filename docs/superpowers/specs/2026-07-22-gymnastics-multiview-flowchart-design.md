# 体操マルチビュー解析フロー図デザイン

## 目的

現在の体操動作解析パイプラインを、日本語の横長 16:9 図として一枚に整理する。前半の共通データ処理を簡潔に示し、後半のマルチビュー情報融合を「ベースライン手法」と「提案手法」の二分岐で詳しく比較する。

## 全体構成

図は左から右へ進むフローチャートとする。共通処理は次の順序で配置する。

1. 正面・側面映像
2. SAM3D-Body による 2D / 3D 関節点抽出
3. 時間同期と動作周期分割

時間同期後、データフローを評価用疑似参照とマルチビュー融合に分岐させる。

- 2D 関節点は三角測量に入力し、「3D 疑似参照」を生成する。
- 正面・側面の 3D 関節点と時間オフセットは、マルチビュー融合に入力する。

三角測量結果は融合モデルの学習入力や教師信号ではなく、最終評価にのみ使用することを図中に明記する。

## マルチビュー融合の二分岐

### ベースライン手法

青系の要素で次の処理を表示する。

1. 安定関節の選択
2. side から face への Sim3 位置合わせ
3. 両視点の平均融合
4. 関節点系列の時間平滑化
5. 融合 3D 姿勢

この分岐は、現在の推奨決定論的手法 `sim3_face_stable_smooth_kpt` を表す。

### 提案手法

橙系の要素で次の処理を表示する。

1. 身体中心座標への正規化
2. 回転特徴と視点間差分特徴の生成
3. 視点交換不変の残差時系列畳み込み融合モデル
4. 融合 3D 姿勢

モデルの下部に自己教師あり学習の補助ブロックを配置し、再現可能な破損、合意性、幾何、時間的一貫性、動作周期全体の回転制約を簡潔に示す。

## 評価と下流処理

二つの融合結果を「3D 疑似参照との比較」に接続し、評価指標として MPJPE を表示する。評価後の任意処理として「動作解析・分類」を配置する。

## 視覚仕様

- 横向き 16:9、左から右へのフロー
- 共通処理は中立色、ベースラインは青、提案手法は橙、評価は緑
- 分岐と合流が一目で分かる直交コネクタ
- 日本語ラベルを使用し、発表スライドで読める文字サイズを確保
- 「3D 疑似参照」は ground truth と表記しない
- 提案手法の学習経路と三角測量評価経路を接続しない

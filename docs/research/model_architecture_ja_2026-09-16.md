## 2. 前段：骨盤中心正規化（決定論的・可逆・非ネットワーク）

各視点・各フレームで独立に：骨盤原点（両股関節中点）、側方軸（右→左股関節方向の正規化）、
初期鉛直方向（骨盤→胸郭、側方軸に直交化）、外積で第3軸 → フレームごとのSO(3)回転行列。
スケールは**試行全体の骨盤–胸郭距離の中央値**（フレーム単位のスケールは揺れるため）。
正規化キーポイント = (x − 原点)·R / スケール。視点固有の並進・向き・スケールを除去する。
実験（RQ1）により、この正規化が性能利得の支配的要因であることが示されている。

## 4. ネットワーク構成（層単位）

**① 共有視点エンコーダ（重み共有、face/sideそれぞれに適用）**
- 関節枝：Linear(9→128) → GELU → Linear(128→128)
- 体幹枝：Linear(14→128) → GELU → Linear(128→128)、出力を全70関節へブロードキャスト加算
  （**回転条件付け**——アブレーションA10はここをゼロ化）
- 加算後GELU、無効位置はゼロ化

**② 対称結合（視点交換不変性の実装点）**
concat[ (face+side)/2 , |face−side| ] → 256次元。平均と絶対差はいずれも対称関数であり、
不一致特徴も全て絶対量のため、**face/sideを入れ替えても入力が厳密に不変**
（学習目標ではなく数学的保証）。

**③ 視点間不一致エンコーダ**：Linear(13→128) → GELU → Linear(128→128)

**④ 融合射影**：Linear(384→128) → GELU（対称結合256＋不一致128の連結）

**⑤ 6ブロック拡張畳み込み残差TCN（時系列主幹）**
- テンソルを [B×70関節, 128ch, Tフレーム] に再配置——**関節ごとに独立して時間方向へ畳み込み**
  （関節間の相互作用は前段エンコーダのみ）
- 各ブロック：Conv1d(128,128,k=3)×2＋GELU＋残差接続、膨張率 1, 2, 4, 8, 16, 32
- 受容野 = 1＋4×(1+2+4+8+16+32) = **253フレーム**、非因果（双方向）、128フレーム学習窓を完全被覆
- 全層マスク伝搬、無効フレームは畳み込みに漏れない

**⑥ 残差ヘッドと有界化**
Linear(128→3) でフレーム・関節ごとの生Δ → tanh(Δ)×0.05（関節別上限、正規化単位）→
**両視点が同時に有効な位置のみ**適用、それ以外はゼロ。

## 5. 出力合成とフォールバック

```
出力 = ベース（品質重み付き平均、detachで勾配切断） + 有界Δ
```

- **ベースバイパスは安全機構**：ネットワークが各関節を動かせるのは最大0.05正規化単位
  （体幹スケールの約5%）まで——決定論的ベースを覆すことは構造的に不可能。
  これが「監査可能な有界修正」の設計である。
- **視点欠損フォールバック**：有効マスク = face有効 ∧ side有効。片視点のみのフレームでは
  Δ≡0となり、出力は品質重み付き単視点へ自然に退化——視点欠損への耐性が構造的に備わる。
- 最終的に正規化座標系からface参照系へ復元（正規化は可逆）して出力。

## 6. アブレーション専用のオプションヘッド（主線A6では未使用）

## 8. 設計哲学（まとめ）

あらゆる「賢さ」を制約の中に閉じ込める設計である：視点交換不変性は対称関数で保証、
修正量はtanh上限で拘束、ベースはdetachで保護、視点欠損はマスクで自動フォールバック。
この制約群と引き換えに得られるのが、論文が誠実に主張できる三点——**監査可能性・運動保持・
ゼロショット転移性**——である。
